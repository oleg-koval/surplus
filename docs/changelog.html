v0.5.0

2026-10-10

Launch debit for Claude bursts and clearer forecast error

Holds back an estimated 1% of the weekly allowance for each premium Claude launch until the next statusline reading, so a burst of launches on one cached reading shrinks its own headroom. The amount is configurable with premiumLaunchDebitPercent, and 0 disables it. The surplus forecast claude error now explains that only a running Claude session saves a reading.

v0.3.0

2026-10-09

Reserve room for the rest of your week

Added reset-scoped workload forecasts. For example, surplus forecast claude 20 budgets 20% expected usage before the current reset. A forecast cannot weaken the normal reserve guard and is ignored after its reset window expires.
