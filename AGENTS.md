# Surplus agent guidance

For requests to install, configure, inspect, or troubleshoot Surplus as a user, read [the Surplus skill](skills/surplus/SKILL.md). The skill is also installable by agents outside this repository.

For implementation changes, follow [CONTRIBUTING.md](CONTRIBUTING.md) and the current code. Do not apply the operating skill to unrelated Claude Code, Codex, Hermes, or Pi requests.
